Traefik Lab

Reverse proxy, service discovery, TLS

Reverse proxy и service discovery для стека из нескольких сервисов без ручной правки конфигов: EntryPoint → Router → Middleware → Service, TLS, canary-деплой.

Стек: Traefik 3, Docker Compose, Node.js, PostgreSQL, mkcert / Let's Encrypt. Уровень: Низкая–средняя.

Пять сущностей на пути запроса

Запрос проходит EntryPoint, затем Router, цепочку Middleware и Service. Providers — источник этих правил; их можно комбинировать: часть в labels, общие middlewares в файле.

  • EntryPoint — порт, Provider — источник конфигурации
  • Router сопоставляет Host и Path
  • Статическая и динамическая конфигурация

Маршруты в labels контейнера

Traefik читает Docker-сокет и создаёт роуты по labels на лету. Ловушка: без exposedByDefault=false маршрут получит любой контейнер, а неверный порт сервиса даёт 502 Bad Gateway.

  • Формат traefik.http.routers.<имя>.<свойство>
  • Явное включение через traefik.enable=true
  • loadbalancer.server.port — порт внутри контейнера

Цепочка обработки запроса

Rate limit, заголовки, basicAuth и stripPrefix подключаются к роутеру списком. Порядок важен: middleware, который должен сработать и на отказных ответах, ставят первым.

  • Общие middlewares в dynamic/middlewares.yml
  • rateLimit: average и burst
  • Порядок в router.middlewares

Load balancing и canary

По умолчанию реплики получают трафик по round robin, нездоровые исключаются health check-ом. Для canary-релиза два сервиса оборачиваются в weighted service с долей трафика.

  • Round robin и health check
  • Weighted service: 90% на 10%
  • Суффикс @docker для сервисов из labels

mkcert и Let's Encrypt

mkcert подходит для локальной разработки, Let's Encrypt — для реального домена. Сначала всегда staging-резолвер: он не тратит лимиты боевого CA, а переключение на продакшен — одна строка.

  • HTTP-01 challenge через entrypoint web
  • Staging против production
  • acme.json как хранилище сертификатов
