Traefik Lab

Reverse proxy, service discovery, TLS

Reverse proxy, который сам находит контейнеры: маршруты, middleware, балансировка и canary, TLS (mkcert, ACME), TCP/UDP и наблюдаемость на сквозном проекте CoffeeShop — от трёх открытых портов до одного входа.

Стек: Traefik v3.7, Docker Compose, Node.js, PostgreSQL, mkcert / ACME (Pebble), Prometheus / Grafana. Уровень: Низкая–средняя.

Путь запроса: вход → роутер → middleware → сервис

Статическая конфигурация (traefik.yml) читается при запуске, динамическая (метки контейнеров, файлы) — на лету. Первый вопрос при любой поломке: чей это ответ — Traefik или приложения.

  • 404 page not found — роутер не найден; 502/503/504 — проблема сервиса
  • exposedByDefault: false и traefik.enable=true
  • Дашборд и журнал показывают, как Traefik понял метки

Маршрут одной строкой на контейнере

Метки читаются слева направо: протокол, тип объекта, имя, поле. Имена общие на весь Traefik — добавляй префикс проекта. Знак $ в метках Compose удваивают.

  • Host(), PathPrefix(), Header(), Method() и их комбинации
  • Приоритет по умолчанию — длина правила
  • stripprefix, redirect, headers, basicAuth подключаются к роутеру списком

Лимиты, повторы, предохранитель

rateLimit режет частоту, inFlightReq — параллельность, ipAllowList — адреса. retry повторяет запрос, только если не удалось соединиться, а circuitBreaker сам отвечает 503, когда сервис болен.

  • 429 с заголовком Retry-After
  • Повтор POST без ключа идемпотентности создаёт дубли
  • Подделка X-Forwarded-For: trustedIPs только для своих прокси

Healthcheck, canary и blue/green

Несколько копий сервиса Traefik балансирует по кругу, больных исключает healthcheck. Для canary и blue/green составной сервис с весами описывается в файле и меняется без перезапуска.

  • Round robin, sticky cookie
  • Weighted: 90/10 → 50/50 → 0/100
  • Mirroring: копия трафика на новую версию

mkcert, mTLS и автоматические сертификаты

Локально HTTPS даёт mkcert; для настоящего домена Traefik сам заказывает сертификаты по ACME (HTTP-01, TLS-ALPN-01, DNS-01 для wildcard). Отлаживай на staging, acme.json держи на томе с правами 600.

  • TLS options: minVersion, sniStrict, клиентские сертификаты (mTLS)
  • Wildcard — только DNS-01; токены DNS-провайдера вне git
  • HTTP/3 — http3: {} и порт 443/udp
