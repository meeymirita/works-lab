CoffeeOps — shell и bash с нуля

Командная строка и bash с нуля: терминал и оболочка, переменные и кавычки, условия и циклы, функции и shellcheck, потоки и конвейеры, массивы и строки, grep / sed / awk, cron и деплой-скрипт с откатом.

Стек: Bash 5, Docker, grep / sed / awk, shellcheck. Уровень: Базовая.

Оболочка делит строку на слова

Главное правило bash: строка режется по пробелам. Кавычки решают, сколько слов получится и что раскроется. Переменные всегда берём в двойные кавычки.

  • без кавычек — слова делятся
  • "…" — переменные раскрываются, слова целые
  • '…' — всё буквально

Скрипт должен падать громко

По умолчанию bash идёт дальше после ошибки и может «успешно» закончить сломанную работу. Три настройки и ловушка EXIT делают провал заметным и убирают за собой.

  • set -e — остановиться на ошибке
  • set -u — ошибка на пустой переменной
  • trap … EXIT — уборка при любом выходе

Маленькие программы собираются в цепочку

Конвейер соединяет вывод одной команды со вводом следующей. Так за минуту строится отчёт: берём столбец, сортируем, считаем повторы, показываем лидеров.

  • cut — взять столбец
  • sort | uniq -c — посчитать повторы
  • head — оставить первые строки

Счётчик без внешних утилит

Ассоциативный массив работает как словарь «ключ → значение». Им считают заказы по товарам прямо в bash: ключ — название, значение — сумма.

  • declare -A — объявление (bash 4+)
  • ${m[$k]:-0} — значение или 0
  • ${!m[@]} — все ключи
