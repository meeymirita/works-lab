Centrifugo Lab

Realtime Workspace — Centrifugo с нуля

Realtime-сервер Centrifugo для Laravel + Vue: каналы и namespaces, centrifuge-js, публикация из Laravel, JWT и subscription tokens, proxy, presence и history, recovery, Outbox, тесты, production и нагрузка.

Стек: Centrifugo 6, Laravel 13, Vue, Docker, Redis. Уровень: Средняя–высокая.

Origin и каналы — в одном JSON

Centrifugo настраивается файлом config.json. allowed_origins защищает от подключений с чужих страниц: браузер с другого origin получит отказ.

  • client.allowed_origins — список разрешённых адресов страниц
  • namespaces делят каналы по правилам
  • http_api.key — ключ для публикации с бэкенда

Подписка на канал и её события

В centrifuge-js подписка — отдельный объект со своими состояниями: subscribing, subscribed, unsubscribed. Приходящие сообщения — событие publication.

  • client.newSubscription(channel) создаёт подписку
  • sub.on('state') — переходы состояний
  • sub.on('publication') — входящие сообщения

Laravel выдаёт connection-токен

Клиент не знает секрета: Laravel подписывает короткоживущий JWT, а Centrifugo его проверяет. sub — строка с id пользователя, exp — срок жизни.

  • HS256 и общий hmac_secret_key
  • sub — строкой, не числом
  • короткий exp + getToken на клиенте

Laravel решает, кого пускать в канал

Subscribe proxy: Centrifugo при каждой подписке спрашивает у Laravel, можно ли. Ответ — result или error с кодом.

  • endpoint и timeout в channel.proxy.subscribe
  • proxy включается на namespace
  • 403 — отказ, result.info — данные пользователя
