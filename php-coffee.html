Coffee Shop API на PHP 8.4

ООП на PHP 8.4 с нуля на маленьком API кофейни: 4 принципа ООП, Factory, Decorator, Strategy, Repository, SOLID, наследование vs композиция.

Стек: PHP 8.4, Laravel 13, PostgreSQL, RabbitMQ. Уровень: Базовая.

Money: деньги как значение

Деньги хранятся целыми копейками, объект неизменяем, а равенство считается по содержимому. Ловушка: readonly защищает свойство, но не объект внутри него.

  • private-конструктор и static-фабрики
  • readonly и «изменение» через новый объект
  • equals() против ===
  • минус на входе отсекается сразу

От копипасты к abstract Drink

Два класса «в лоб» дублируют формулу цены. Общий скелет уходит в абстрактного родителя, а дочерним остаются только «дырки»: название и базовая цена.

  • abstract-методы и хуки по желанию
  • final-скелет, который нельзя переопределить
  • enum Size с match для наценки

Order охраняет свои инварианты

Единственное изменяемое состояние заказа закрыто, а любое действие проходит через проверки. Вывод: инвариант, который можно обойти снаружи, инвариантом не является.

  • private-состояние и исключения на нарушения
  • нельзя оплатить пустой или изменить оплаченный заказ
  • lines() отдаёт копию массива

Добавки поверх напитка

Овсяное молоко, шот и сироп оборачивают напиток и достраивают название и цену. Композиция вместо взрыва подклассов «Латте с сиропом и молоком».

  • общий интерфейс Beverage у напитка и добавки
  • абстрактный BeverageDecorator хранит обёрнутый объект
  • enum Extra как фабрика добавок

Скидки как объекты

Каждая акция — отдельный класс с одним интерфейсом, а «текущее время» тоже интерфейс, поэтому happy hour проверяется в тесте с подменой часов.

  • DiscountPolicy и подмена стратегий без if в кассе
  • NoDiscount как Null Object
  • композиция: условие плюс любая другая стратегия

Домен не знает про инфраструктуру

Домен говорит только интерфейсами: «сохранить заказ», «опубликовать событие». Eloquent и RabbitMQ подключаются снаружи и заменяются в тестах на in-memory версии.

  • OrderRepository: интерфейс в домене, Eloquent в Infrastructure
  • EventPublisher и AMQP-реализация
  • сквозной тест без БД и брокера
