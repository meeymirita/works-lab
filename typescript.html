Warehouse — складской учёт

Типизация домена складского учёта с нуля: generics, размеченные объединения, mapped/conditional types, CLI на Zod, сквозная типизация API + Vue.

Стек: TypeScript 6, Node 24+, Zod, Vitest. Уровень: Высокая.

Тип — это форма, а не имя

Значение подходит под тип, если у него есть все нужные поля. Ловушка: два alias на string взаимозаменяемы, и перепутанные аргументы компилируются.

  • Лишние поля у переменной не мешают
  • Литерал в аннотации проходит excess property check
  • Различить одинаковые по форме типы помогают branded types

Discriminated union

Вариант события определяется литеральным полем kind, и внутри case тип сужается до нужного варианта. Ветка default с never превращает забытый вариант в ошибку компиляции.

  • У каждого варианта только его поля
  • switch по дискриминанту сужает тип
  • assertNever проверяет полноту разбора

Тип как параметр

Generic нужен, когда тип на входе должен сохраниться на выходе. Если параметр T встречается в сигнатуре один раз, достаточно unknown.

  • Ограничения через extends keyof T
  • Generic-типы: Result и Paginated
  • Generic-репозиторий для любой сущности с id

Как устроены типы-утилиты

Partial, Pick и Extract построены на трёх механизмах: mapped, conditional и template literal типах. Их достаточно узнавать в сигнатурах библиотек, изобретать каждый день не нужно.

  • Mapped проходит по ключам и строит новый тип
  • Conditional с infer вытаскивает вложенный тип
  • Template literal собирает строковые union

Внешние данные не заслуживают доверия

Типы стираются при компиляции, поэтому всё, что пришло извне, имеет тип unknown. Пока значение не проверено, обращаться к его полям нельзя.

  • unknown безопаснее any
  • Сужение через typeof, in и проверку на null
  • never описывает недостижимые ветки

Схема как источник типа

Zod проверяет данные в рантайме, а тип выводится из той же схемы через z.infer. Результат safeParse сам является размеченным объединением.

  • Один источник правды для рантайма и компилятора
  • z.discriminatedUnion повторяет union из домена
  • safeParse возвращает success или error без исключения
