CSS Lab

FrontFest — сайт конференции

Современный CSS с нуля на сайте фронтенд-конференции: каскад и @layer, токены, oklch и тёмная тема через light-dark(), Flexbox, Grid и subgrid, адаптив и container queries, :has() и формы, sticky, анимации и view transitions. Разметка готовая — вы пишете только стили, без фреймворков и препроцессоров.

Стек: CSS, @layer, Grid, Container Queries, oklch. Уровень: Базовая.

Слои вместо войны специфичности

Чужой CSS с #id и !important перебить обычными средствами нельзя. Порядок слоёв проверяется раньше специфичности, поэтому один объявленный порядок решает проблему без хаков.

  • Порядок слоёв объявляется одной строкой
  • @import ... layer(...) для каждого файла
  • У !important порядок слоёв переворачивается

oklch и light-dark()

Вся палитра строится от одного оттенка, а тёмная тема задаётся вторым значением в light-dark(). Ловушка: жёстко заданный цвет в компоненте не переключается вместе с темой.

  • oklch: предсказуемая светлота
  • color-mix и относительный синтаксис для производных
  • color-scheme: light dark и ручной data-theme

Grid без медиазапросов

Сетка спикеров сама решает, сколько колонок помещается. Ловушка: minmax(18rem, 1fr) даёт горизонтальный скролл на узком экране, пока минимум не обёрнут в min().

  • auto-fill против auto-fit
  • min(100%, 18rem) спасает узкие экраны
  • Дальше subgrid выравнивает строки карточек тарифов

Компонент знает своё место

Карточка спикера должна зависеть от ширины контейнера, а не окна: одна и та же карточка встречается в сетке и в узкой колонке. Медиазапрос этого не различает.

  • container-type: inline-size на предке
  • @container вместо @media
  • Единицы cqi для шрифта от ширины карточки

Состояние без JavaScript

Родительский селектор :has() подсвечивает поле по состоянию его input и показывает блок по выбранному тарифу. :user-invalid, в отличие от :invalid, срабатывает только после взаимодействия.

  • Ошибка только после работы с полем
  • Показать блок по :checked без JS
  • Вложенность CSS с &

@property и popover

Регистрация переменной через @property учит браузер интерполировать угол, поэтому градиентная рамка вращается плавно. Для поповера @starting-style задаёт точку старта анимации из display: none.

  • @property с типом <angle>
  • transition ... allow-discrete
  • prefers-reduced-motion как обязательное уважение к пользователю
